# DP-Computer-Science
Materials for the first assessment 2027 DP Computer Science curriculum.

## Organization
Resource numbers are formatted as "Topic-Sequence - Name". So the 3rd lesson in topic A2 will be formatted as "Lesson A2-3 - Name of Lesson".
### Topic A1 - Computer Fundamnentals
### Topic A2 - Networks
### Topic A3 - Databases
### Topic A4 - Machine Learning
### Topic C - Case Study (marked with year of case study exmaination)
### Topic B1 - Computational Thinking
### Topic B2 - Programming
### Topic B3 - Object-Oriented Programming
### Topic B4 - Abstract Data Types
### Topic IA - Internal Assessment

# Directory:
## Lessons:
Powerpoint presentations including code snippets and labs/programming assignments/worksheets at the end. 

## Programming Assignments:
Python assignments intended to take 60-120 minutes.

## Worksheets:
Questions, activies, or otherwise work on paper that can vary in time.

## Projects:
Larger assignments that correspond to the unit's overall themes. Can be programming or paper based.
